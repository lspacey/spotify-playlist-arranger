# ─── CUDA acceleration (Windows / Linux) — OPTIONAL ────────────────────────────
#   RTX 5080 / 50-series Blackwell GPUs (sm_120) require CUDA >= 12.8.
#   PyTorch >= 2.7.0 + cu128/cu130 wheels include sm_120 kernels.
#   This project is confirmed working with torch 2.12.1+cu130 (CUDA 13.0).
#
#   To switch from CPU to CUDA on RTX 5080:
#
#     1. Uninstall CPU torch:
#        pip uninstall torch torchaudio -y
#
#     2. Install CUDA-enabled matched pair from the OFFICIAL PyTorch index:
#        pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu130
#        → This installs torch 2.12.1+cu130 + torchaudio 2.11.0+cu130
#
#     3. Verify (expect: True, RTX 5080, sm_120 in arch list):
#        python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0)); print(torch.cuda.get_arch_list())"
#
#   For OLDER GPUs (RTX 20/30/40 series) use CUDA 12.1 wheels:
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
#
#   IMPORTANT: Only install PyTorch from the OFFICIAL index at download.pytorch.org.
#   Do NOT install any third-party packages claiming to "fix" RTX 5080 compatibility.
#
#   The mert.py module auto-detects GPU availability and moves the model
#   to CUDA when available. No config changes needed.
